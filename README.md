## 📖 项目简介

本项目基于课程实验《造字游戏》进行**创意编程改造**，模拟完整实验流程：**造词 → 给出意思 → 绘制提示图 → 他人猜词 → 算法评分 → AI 互动**。

游戏使用《32块方块上的192字.xlsx》数据集，每局随机抽取 4 个方块（每块 6 个字），玩家从每个方块中各选一个字，**组成一个自造的四字词语**并给出意思；猜词人根据词语和提示图像猜测含义，由算法自动计算相似度得分，并可与 ChatGPT、DALL-E 互动。

相比原实验的改进：

- 用**算法自动评分**替代人工手动打分
- 新增**绘画环节**，出词人可绘制提示图像
- 新增 **ChatGPT 猜测词语意思**环节
- 新增 **DALL-E 基于猜测意思生成图像**环节
- 增加简单**特效与音效**，提升趣味性

## ✨ 创新点

| 创新点 | 说明 |
|--------|------|
| 🖥️ **GUI 界面** | 通过图形用户界面增加整个过程的互动性，简单便捷 |
| 🔊 **特效及音效** | 运行时有背景音乐；选取不同方块上的字有不同音效；鼠标悬停按钮和文字有动态变色效果；可在"设置"界面自定义各音效音量及背景音乐播放/暂停 |
| 💾 **信息存储** | 词语及意思直接存入"出词人"表格，词语和猜测意思存入"猜词人"表格；出词人可多次造词，猜词人可多次猜词，替代手动填写表格 |
| 🎨 **绘制功能** | 出词人可用鼠标在画板上绘制与词语相关的图像作为提示；猜词人点击"提示"查看图像，让参与者创造性更强 |
| 🤖 **ChatGPT 猜测意思** | 让 ChatGPT 作为游戏猜词人，对出词人所造的词语进行意思猜测，增添 AI 互动 |
| 🖼️ **DALL-E 画图** | 基于 ChatGPT 所猜测的意思生成图像，AI 与图像互动，不再仅仅是文字 |
| 📊 **自动计算相似度** | 避免人工打分，用相关算法直接评估出词人填入的意思与猜词人猜测意思的相近程度 |

│
▼
主菜单 ──► 设置（音量调节 / 背景音乐播放暂停）
│
▼ 开始游戏
角色选择 ──┬──► 出词人 ──► 随机 4 方块选字组词 ──► 填写词语意思 ──► 提交
│ │
│ ▼
│ 绘制提示图像（可选）
│
└──► 猜词人 ──► 浏览词语 ──► 查看提示图像 ──► 输入猜测意思 ──► 提交
│ │
│ ▼
│ 相似度得分
│
├──► ChatGPT 解释词语
└──► DALL-E 生成图像


### 出词人流程

1. 系统从 192 字中**随机选取 4 个方块**（控制台输出方块序号与行数据），不同方块音效不同；
2. 点击每个方块上的文字，下方黑色方框依次显示所选字，组成四字自造词；
3. 在文本框内**输入所造词语的意思**，点击"提交"（弹窗提示提交成功）；
4. 点击"绘制"进入画板，**绘制与词语意思相关的图像**，保存后作为给猜词人的提示。

### 猜词人流程

1. 界面中央显示出词人所造词语，"上一行 / 下一行"可切换浏览出词人表格中的词语；
2. 点击"提示"查看出词人绘制的图像；
3. 在文本框输入猜测的意思，点击"提交"后：
   - 信息存入猜词人表格
   - 弹窗给出与原本意思的**相似度得分**（如：相似度得分： 86）
   - 词语下方显示出词人给出的原本意思
4. 点击 **ChatGPT 解释**：弹出 ChatGPT 对该自造词的猜测解释（控制台显示本次对话费用）；
5. 点击**显示图像**：弹出 DALL-E 模型生成的图像链接，点击进入网址即可查看 AI 绘制的图像。

## 🖼️ 界面展示

> 💡 建议将各界面截图放入 `docs/images/` 目录后取消注释以下图片引用。

### 主菜单

启动程序后进入主菜单，云朵背景，鼠标悬停按钮时颜色变化，运行即有 BGM。

markdown


### 设置界面

可滑动滑块调整方块一~四音效、按钮音效、背景音乐的音量，点击"播放/暂停"控制背景音乐。

markdown


### 角色选择

可选择"出词人"或"猜词人"身份。

markdown


### 出词人界面

四个方块从 192 字表中随机选取，点击方块文字填入下方方框组成词语，文本框输入词语意思，支持提交与绘制。

markdown


### 绘制界面

鼠标绘制与词语意思相关的图案作为提示，`Clear` 清除画板，`Save` 保存图像。

markdown


### 猜词人界面

中央为所造词语，支持上一行/下一行切换、查看提示图像、输入猜测并提交得分、ChatGPT 解释、DALL-E 显示图像。

## ⚙️ 配置说明

| 配置项 | 位置 | 说明 |
|--------|------|------|
| OpenAI API Key | 猜词人模块代码 | ChatGPT / DALL-E 调用凭证，建议用环境变量 |
| 背景图路径 | 各界面代码中 | 替换 `1.jpg ~ 6.jpg` 或修改为自定义图片 |
| 音效音量 | 程序内"设置"界面 | 运行时滑块调节，无需改代码 |
| 词语数据 | `32块方块上的192字.xlsx` | 可自行扩充方块与字符 |
